# WSP User Scripts
This script will be useful for those who are forced to use WPS software.
If you accidentally found this repository, you don't need it.

Use Tampermonkey or a similar plugin for your browser.


## Verified on WSP V37.0.0.25

### WSP_pageoperator_ui.user.js
UI improvements for the WSP operator: font, tiles, accordion, ribbon click, tooltip, connection indicator, tab memory, one‑time activation of hiding checkboxes. WSP_pageoperator will now be divided into several scripts, and the UI will be separated.

### WSP_more_events.user.js
The “More events” button in the WSP object card (requesting the log for 14 days). This part of the functions was moved from the old version of the WSP_pageoperator

### WSP_sync_object_names.user.js
Synchronization of object names: nameobj from managerobject to full_name via WSP V37.*.

### WSP_user_sync.user.js
Adds a button to synchronize objects for users on the “Access Manager” page. Updated version of WSP_pagemanageraccess.user.js for WSP V37.*
